# AI Coding Handbook

LLMs are *incredible productivity boosters* if you use them with *precision*, *judgment*, and *taste*. **This course will teach you to use agentic AI tooling effectively as a developer.** We'll use [OpenCode](https://opencode.ai/), but everything we cover also applies to tools like [Claude Code](https://claude.com/product/claude-code), [Codex](https://openai.com/codex/), and the rest.

**This is not a course on vibe coding!** This is a course for people with *at least* a basic understanding of code, who want to boost their productivity.
